# QuickShot

小而快的 Windows 截图标注工具：启动即截、框选标注、回车进剪贴板。

| 指标 | 数值 |
|---|---|
| 单文件体积 | 74.5 KB |
| 冷启动到可框选 | 约 0.26 s（热启动 0.17 s） |
| 第三方依赖 | 无，仅系统自带 .NET Framework 4.x |
| 常驻 / 联网 / 配置文件 | 全无，截完即退 |

中文字体图标内嵌，不依赖任何外部资源文件。

## 下载

到 [Releases](https://github.com/yzjn6/QuickShot/releases) 下载 `QuickShot.exe`，双击运行，无需安装。

## 使用流程

1. 双击 `QuickShot.exe`，程序立即抓取整个虚拟桌面并压暗显示
2. 按住左键框选区域（宽或高小于 4 px 不会生效），松开后弹出工具栏
3. 选择标注工具并绘制
4. 按 `Enter` 或双击选区，图片进入剪贴板；也可 `Ctrl+S` 存成 PNG
5. 右键或 `Esc` 退出

## 功能

### 取景

- 覆盖全部显示器，支持副屏在左/上导致的负坐标
- Per-Monitor V2 DPI 感知，高缩放比例下坐标与线宽正确
- 光标跟随放大镜：取样 50×30、3 倍最近邻放大、带十字准线与边框，贴近屏幕边缘时自动翻转
- 放大镜内实时显示 HEX、RGB、CMYK 与屏幕坐标

### 标注工具

| 工具 | 参数 | 说明 |
|---|---|---|
| 拖动 | — | 移动或缩放已有图元，不新建 |
| 矩形 | 描边 1~16，默认 3 | 可切换填充；`Shift` 约束为正方形 |
| 椭圆 | 描边 1~16，默认 3 | 可切换填充；`Shift` 约束为正圆 |
| 箭头 | 尺寸 8~60，默认 18 | 6 点自绘多边形，可切换实心；`Shift` 吸附到 8 个方向 |
| 编号 | 半径默认 16，最小 6 | 圆环加尖角徽章，序号自动取当前最大值 +1；在图元上滚轮可调半径 |
| 线条 | 粗细 1~60，默认 3 | 自由曲线笔刷，可切换半透明 |
| 文字 | 字号 16~66，默认 26 | 粗体、斜体独立开关；双击已有文字可再次编辑 |
| 马赛克 | 笔刷 26~86，默认 32 | 矩形/笔刷双模式，块大小 `max(6, 宽/3)`，按块取平均 |
| 擦除 | 笔刷 26~86，默认 32 | 用原位图覆盖，露出原图而非删除图元，有矩形/笔刷双模式 |

### 图元编辑

- 单选后可拖动，八个方向手柄可缩放
- 撤销、重做、删除
- 9 色板随时换色，属性改动实时生效

### 输出

- 剪贴板同时写入 `CF_DIBV5`、`CF_DIB` 与注册格式 `PNG`，粘贴进微信、QQ、飞书等均正常
- 直接另存为 PNG

## 快捷键

| 操作 | 快捷键 |
|---|---|
| 复制到剪贴板并退出 | `Enter` 或双击选区 |
| 退出 / 取消当前绘制 / 回到拖动 | `Esc`、右键 |
| 撤销 | `Ctrl+Z` |
| 重做 | `Ctrl+Y` 或 `Ctrl+Shift+Z` |
| 删除选中图元 | `Delete` |
| 保存 PNG | `Ctrl+S` |
| 复制像素 HEX | `Ctrl+H`（取景态） |
| 复制像素 RGB | `Ctrl+R`（取景态） |
| 复制像素 CMYK | `Ctrl+K`（取景态） |
| 复制屏幕坐标 | `Ctrl+P`（取景态） |
| 约束比例 / 方向吸附 | 绘制时按 `Shift` |

## 构建

不使用 csproj，也不使用 NuGet，直接用系统自带的 `csc.exe` 编译：

```powershell
.\build.ps1
```

脚本会调用 `%windir%\Microsoft.NET\Framework64\v4.0.30319\csc.exe`，以 `/recurse:"src\*.cs"` 编译全部源码，并把 `Res` 下的图标字体与程序图标嵌入 exe。

## 自测

```powershell
.\QuickShot.exe --selftest
```

无界面运行，输出一行结果并以退出码表示结论：`0` 通过，`2` 剪贴板写入失败，`3` 渲染或几何断言失败。覆盖内容包括图元命中测试、箭头八方向吸附、马赛克块大小、CMYK 换算、剪贴板多格式写入以及自绘控件的实例化绘制。

## 目录结构

```
src/
  Program.cs       入口、DPI 感知、异常兜底、无头自测
  CaptureForm.cs   全屏取景窗口与标注交互状态机
  Controls.cs      自绘控件：图标按钮、滑块、色板、开关
  Clipboard.cs     剪贴板写入（CF_DIBV5 / CF_DIB / PNG）
  IconFont.cs      内嵌图标字体加载
  Native.cs        Win32 互操作
  Theme.cs         配色常量
  Shapes/
    ShapeBase.cs     图元基类、绘制上下文、马赛克合成
    Shapes.cs        矩形、椭圆、箭头、编号、文字、线条、马赛克、擦除
    ShapeDragger.cs  拖拽、八向手柄与光标映射
    ArrowGeometry.cs 八方向吸附几何
Res/               编译期嵌入资源（图标字体、程序图标）
build.ps1          编译脚本
```
